# Michael Festschrift Project

This repository organizes source materials, contributor coordination, editorial planning, drafts, and generated exports for a festschrift for Michael.

## Working Goal

Produce a coherent, accurate, and warmly written collection honoring Michael. The occasion, audience, contributors, schedule, publication format, and distribution plan remain to be confirmed.

## Current Contents

- `sources/INDEX.md`: inventory template for source materials, submissions, and provenance.
- `sources/`: read-only normalized source materials and reference notes.
- `raw/`: staged originals, submissions, images, scans, recordings, and intermediary conversions.
- `analysis/FESTSCHRIFT-BRIEF.md`: working scope, open decisions, and proposed workflow.
- `drafts/`: editable outreach, contributor guidance, manuscript sections, captions, and working notes.
- `archive/`: superseded draft snapshots.
- `output/`: generated review and publication exports.

## Current Status

- The repository structure and steering files are initialized from the conventions used in `../network-search`.
- No project-specific source material has been imported.
- No biographical facts, contributors, dates, permissions, or publication requirements are assumed.
- The next checkpoint is to confirm the project brief before drafting or outreach begins.
